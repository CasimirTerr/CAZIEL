    How it works

    Six layers, one chain

    IAM analyzers stop at the policy, robot tools stop at the ROS graph, and safety engineers start at the motor. Caziel walks the whole path offline from files you already have, reports only what connects end to end, and then watches live traffic for the paths it found.

    The physics

    Turning a policy into joules

    ISO/TS 15066 models a robot hitting a person as a fully inelastic collision, with the body region acting as a spring. That gives a pain-threshold energy for each region, and from it a speed the robot must stay under.

    Emax = F² / 2kEnergy a body region absorbs at its transient force limit F, with tissue stiffness k.
    E = ½ · μ · v²Energy transferred at relative speed v.
    μ = (1/mH + 1/mR)⁻¹Reduced mass of body region and robot. A mobile base moves as one body, so mR is its full mass. For an arm the standard uses mR = M/2 + payload.
    vsafe = F / √(μ·k)The speed that lands exactly on the limit. caziel fix caps shared-zone speed below it.

    Region values are the ones commonly cited from ISO/TS 15066:2016 Annex A, now informative Annex M of ISO 10218-2:2025. They can be overridden per fleet. These are estimates for ranking security risk, not a functional-safety assessment.

    The fix

    What caziel fix changed

    The fix writes a complete hardened copy of the fleet and scans it again, so every claim below is checked by the same engine. Where a workflow has a safe version, it stays. The "nudge a stuck robot" tool still works, but it now goes through the collision monitor and needs approval. Flip the live view to After to see the same shift against the fixed fleet.

    Still to do by hand

      Run it

      Point it at your own fleet

      Pure Python, one dependency (PyYAML), no cloud credentials needed. It reads exported policies and a graph snapshot, so it's safe to run in CI.

      # install
$ pip install git+https://github.com/CasimirTerr/CAZIEL

# what could happen: scan the example fleet (text, Markdown or JSON)
$ caziel scan examples/harbor-fleet --fail-on critical

# what is happening: classify IoT Core traffic as it arrives
$ caziel watch examples/harbor-fleet examples/harbor-fleet/traffic/shift.jsonl
$ aws logs tail /iot/fleet-commands --follow --format short | cut -d' ' -f3- | caziel watch my-fleet

# write a hardened copy and re-check it
$ caziel fix examples/harbor-fleet -o hardened/

# on the robot: capture the live ROS 2 graph and parameters
$ caziel snapshot -o graph.json --params params.yaml
