# Examples

- **`harbor-fleet/`**: a fictional 12-robot warehouse fleet (KX-1 mobile manipulators) with mistakes that are easy to make in real deployments. Two examples are a "nudge" bridge mapping that skips the collision monitor, and a shared Lambda role for every agent tool.
- **`harbor-fleet-hardened/`**: generated by `caziel fix harbor-fleet -o harbor-fleet-hardened`. Do not edit by hand. Regenerate with `python scripts/build_site_data.py`. Its `caziel-fix/` folder holds `CHANGES.md`, the SROS2 policy and the SCP.

`robots/kx1/graph.json` in the hardened copy is a *projection* (marked `projected_by`). It shows what the graph should look like once SROS2 is deployed. Re-capture with `caziel snapshot` to confirm.
