## Changes

| Area | Target | Change | Why |
|---|---|---|---|
| bridge | `kx1-edge-bridge: fleet/{thing}/cmd/velocity` | Retargeted from /cmd_vel to /cmd_vel_smoothed and set requires_approval | Commands on this mapping now pass through the collision monitor, so a nudge still works but cannot drive into a person. |
| bridge | `kx1-edge-bridge: fleet/{thing}/cmd/pick` | Set requires_approval | The arm can reach a person standing next to the robot, and MoveIt does not see people. A human confirms each pick near staff. |
| bridge | `kx1-edge-bridge: fleet/{thing}/cmd/arm` | Removed | Raw joint trajectories skip MoveIt. Replay taught motions through MoveIt (ExecuteTrajectory or MoveGroup) so collision checks and velocity scaling apply. |
| bridge | `kx1-edge-bridge: fleet/{thing}/cmd/param` | Removed | Wildcard parameter writes let a cloud message raise speed limits or disable collision zones. Use Nav2 speed filter zones for 'slow down in busy aisles' instead. |
